## 配置怎麼選：三種常見用途的判斷標準

記憶體是低價 VPS 最先碰到的天花板，選檔位時照這個思路對號入座。

**純靜態站、個人部落格、測試機**：1GB 年付 $10.99 的入門款夠用，網頁本身就是幾個頁面加輕量 Nginx。真要跑點東西，加個 swap 撐著也行。

**WordPress＋資料庫、小型電商、輕量應用**：3GB 或 4GB 比較穩。MySQL 加 PHP 的組合在 1GB 機器上很容易吃滿，2GB 是底線，預算允許就別貼著底線買。

**資料庫讀寫頻繁、多站點、Docker 跑多個容器**：8GB 起跳。這個檔位以上年付已超過 80 美元，反而該問自己：是不是該看看大廠的彈性計費了。

還有一條所有低價 VPS 通用的規矩：長時間把 CPU 吃滿、或拿機器發垃圾郵件，帳戶可能被直接停權。便宜資源是給正常用量準備的，挖礦腳本就別想了。
